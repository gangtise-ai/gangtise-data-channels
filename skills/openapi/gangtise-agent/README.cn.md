# 投研 Agent 文本

一站式调取 Gangtise 的投研结论文本：一页通、投资逻辑、同业对比、业绩点评、观点 PK、主题跟踪、调研提纲、热点与线索。

---

## 适用场景

- 快速了解一家公司：核心要素、投资主线、竞争格局
- 财报期业绩点评，或对某个市场观点做正反辨析
- 晨会前浏览当日热点话题与核心标的
- 按个股/行业梳理近期研报、纪要、公告中的投研线索

## 怎么用

- 「给我贵州茅台的一页通和投资逻辑」
- 「宁德时代最新一期业绩点评」
- 「观点 PK：光伏产能出清已近尾声」
- 「今天早报的热点话题和核心标的」

> 文本为定期更新，时效性有限，建议配合实时数据与文档检索使用。

## 输出

可直接引用的 Markdown 投研文本；热点与线索类以结构化表格呈现。
