# Knowledge Base Search

Semantic search over the Gangtise research knowledge base. It returns relevant passages from reports, transcripts, and commentary.

---

## When to use

- Find market views and the key wording on a topic
- Pull evidence and data sources for writing or Q&A
- Read the relevant excerpts first, then decide whether to download the original

## How to use

- "Sungrow main business"
- "BYD overseas sales"
- "Views on the gold price in meeting notes from the past month"

> Results are excerpts and may lack context. Check the original before relying on an important conclusion.

## Output

A list of relevant passages with source and date. The original document can be downloaded.
