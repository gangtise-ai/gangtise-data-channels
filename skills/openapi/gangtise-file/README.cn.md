# 投研文档检索

按类型、日期、证券等条件在 Gangtise 文件中心定位文档，并可下载全文。

---

## 适用场景

- 找某只股票近期的研报、公告、会议纪要
- 查外资研报、首席观点、公众号资讯、投资者问答
- 浏览路演、调研、策略会、财报日历等投研日程
- 检索研报图片，为报告配图

## 怎么用

- 「中芯国际最近一个月的券商研报」
- 「贵州茅台 2025 年报和业绩会管理层讨论」
- 「下周有哪些医药公司的路演和调研」
- 「找几张储能装机量相关的研报图表」

> 需要直接阅读、引用段落内容时，用「知识库检索」更合适。

## 输出

文档清单（标题、日期、机构、摘要、文件 ID）；可下载 PDF / Markdown 原文。
