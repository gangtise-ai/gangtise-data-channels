# 上清所估值（Open API · bond/valuation-shclearing）

## 简介

返回上海清算所每日估值：估价全价 / 净价、估价收益率、修正久期、凸性、基点价值、利差久期等。主要覆盖银行间非金融企业债务融资工具（中票、短融、超短融等，代码多为 `.IB`）。多行型：每只债券每个估值日一行。脚本：`scripts/valuation.py`。

数据范围：

- **试用账号**与**正式账号**均支持查询全市场数据，覆盖上交所（`.SH`）、深交所（`.SZ`）、北交所（`.BJ`）、银行间（`.IB`）。
- **数据权限长度**：**试用账号**为当前时间前溯 **3 年**、**正式账号**为前溯 **5 年**的历史存量数据。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `--securities` | 是 | 债券代码 / 简称 / 拼音，逗号分隔；亦可传 `.csv` 路径（读 `security_code` / `code` / `代码` / `债券代码` / `security_abbr` / `债券简称` 列）。非标准代码自动经债券检索解析 |
| `-sd` / `--start-date` | 否 | 估值日期起始；不传默认近 7 日，近 7 日无数据时自动放宽到近 30 日 |
| `-ed` / `--end-date` | 否 | 估值日期截止；不传默认今天 |
| `--confidence` | 否 | 估值可信度：`推荐` / `不推荐`；不传由接口按「推荐」处理 |
| `--field-list` | 否 | 字段英文名或中文名，逗号分隔；传 `all` 返回全部字段。字段不在下表时直接报错并列出可选字段 |
| `-od` / `--output-dir` | 否 | 结果保存目录，建议绝对路径；文件名自动生成 |

## 约束与说明

- 接口按「日历天数 × 债券只数」不超过 10000 预估行数，脚本据此自动把债券分批请求。
- 开始日期早于账号可查询的历史区间（试用账号前溯 3 年、正式账号前溯 5 年）时返回 `110003`，请调晚开始日期。
- 无估值数据的债券不产生行。

## 调用示例

**中票估值：**

```bash
python3 scripts/valuation.py --securities 23万科MTN001 -sd 2026-09-01 -ed 2026-09-30
```

**全部字段：**

```bash
python3 scripts/valuation.py --securities 102381014.IB --field-list all
```

## 返回说明

- **成功**：在 `workspace/gangtise/valuation/` 下生成 `bond_*.csv`（列名为中文），回复中附 Markdown 预览与文件路径。
- **无数据**：全部查询键均无数据时提示未找到。
- **失败**：授权失败、债券无法解析、字段名非法、超出上限等，返回错误说明与处理建议。
