# 债券付息兑付明细（Open API · bond/cash-flow）

## 简介

按兑付日期返回每百元应付利息 / 本金、票面利率、是否免税、应付现金流与兑付后余额。多行型：每只债券每个兑付日一行。脚本：`scripts/cash_flow.py`。

数据范围：

- **试用账号**与**正式账号**均支持查询全市场数据，覆盖上交所（`.SH`）、深交所（`.SZ`）、北交所（`.BJ`）、银行间（`.IB`）。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `--securities` | 是 | 债券代码 / 简称 / 拼音，逗号分隔；亦可传 `.csv` 路径（读 `security_code` / `code` / `代码` / `债券代码` / `security_abbr` / `债券简称` 列）。非标准代码自动经债券检索解析 |
| `-sd` / `--start-date` | 否 | 兑付日期起始；不传返回全部兑付计划 |
| `-ed` / `--end-date` | 否 | 兑付日期截止；不传返回全部兑付计划 |
| `--field-list` | 否 | 字段英文名或中文名，逗号分隔；传 `all` 返回全部字段。字段不在下表时直接报错并列出可选字段 |
| `-od` / `--output-dir` | 否 | 结果保存目录，建议绝对路径；文件名自动生成 |

## 字段说明

不传 `--field-list` 返回全部字段；查询键字段始终返回。

| 字段 | 中文列名 | 默认 | 说明 |
|------|----------|------|------|
| `securityCode` | 债券代码 | 始终 | 债券代码 |
| `paymentDate` | 兑付日期 | 始终 | 兑付日期，格式 `yyyy-MM-dd` |
| `securityName` | 债券简称 | ✓ | 债券简称 |
| `cashFlowType` | 现金流类型 | ✓ | 现金流类型 |
| `interestPer100` | 百元应付利息(元) | ✓ | 每 100 元面值应付利息（单位：元） |
| `principalPer100` | 百元应付本金(元) | ✓ | 每 100 元面值应付本金（单位：元） |
| `couponRate` | 当期票面利率(%) | ✓ | 该计息期的票面利率（单位：%） |
| `taxFree` | 利息是否免税 | ✓ | 该期利息是否免税 |
| `payableCashFlow` | 应付现金流(亿元) | ✓ | 该期应付现金流总额（单位：亿元） |
| `remainingBalance` | 兑付余额(亿元) | ✓ | 该期兑付后债券余额（单位：亿元） |

## 约束与说明

- 脚本先取每只债券的存续期（发行至到期），与 `-sd/-ed` 取交集后按区间分批请求，因此不传日期也能取到未到期的完整兑付计划，大批量债券也不会因区间过长被拒绝。
- `是否免税` 由布尔值转为 `是` / `否`。

## 调用示例

**全部兑付计划：**

```bash
python3 scripts/cash_flow.py --securities 23国债15
```

**未来一年：**

```bash
python3 scripts/cash_flow.py --securities H1万科04,23万科MTN001 -sd 2026-10-01 -ed 2027-09-30
```

## 返回说明

- **成功**：在 `workspace/gangtise/cash_flow/` 下生成 `bond_*.csv`（列名为中文），回复中附 Markdown 预览与文件路径。
- **无数据**：全部查询键均无数据时提示未找到。
- **失败**：授权失败、债券无法解析、字段名非法、超出上限等，返回错误说明与处理建议。
