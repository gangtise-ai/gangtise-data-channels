# 利率债发行计划（Open API · bond/issuance-plan）

## 简介

按计划发行日期返回国债、地方政府债、政策性金融债等利率债的发行计划：发行人、债券类型、期限、计划发行量等。无需指定债券。脚本：`scripts/issuance_plan.py`。

数据范围：

- **试用账号**与**正式账号**均支持查询全市场数据，覆盖上交所（`.SH`）、深交所（`.SZ`）、北交所（`.BJ`）、银行间（`.IB`）。
- **数据权限长度**：**试用账号**为当前时间前溯 **3 年**、**正式账号**为前溯 **5 年**的历史存量数据。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `-sd` / `--start-date` | 否 | 发行日期起始；不传默认今天 |
| `-ed` / `--end-date` | 否 | 发行日期截止；不传默认今天起 30 天 |
| `--field-list` | 否 | 字段英文名或中文名，逗号分隔；传 `all` 返回全部字段。字段不在下表时直接报错并列出可选字段 |
| `-od` / `--output-dir` | 否 | 结果保存目录，建议绝对路径；文件名自动生成 |

## 字段说明

不传 `--field-list` 返回全部字段；查询键字段始终返回。

| 字段 | 中文列名 | 默认 | 说明 |
|------|----------|------|------|
| `issueDate` | 计划发行日期 | 始终 | 计划发行日期，格式 `yyyy-MM-dd` |
| `year` | 年度 | ✓ | 计划所属年度 |
| `issuer` | 发行人 | ✓ | 发行人全称 |
| `bondType` | 债券类型 | ✓ | 债券类型 |
| `term` | 期限(年) | ✓ | 债券期限（单位：年） |
| `issueSize` | 计划发行量(亿元) | ✓ | 计划发行量（单位：亿元） |
| `interestRateType` | 利率类型 | ✓ | 利率类型 |
| `interestFrequency` | 付息频率 | ✓ | 付息频率 |
| `crossMarket` | 是否跨市场 | ✓ | 是否跨市场发行 |

## 约束与说明

- 单次结果超过 10000 行时接口整批拒绝（`100006`）。
- 部分债券类型代码在常量表中没有对应名称，会保留原始代码。

## 调用示例

**下月计划：**

```bash
python3 scripts/issuance_plan.py -sd 2026-10-01 -ed 2026-10-31
```

## 返回说明

- **成功**：在 `workspace/gangtise/issuance_plan/` 下生成 `bond_*.csv`（列名为中文），回复中附 Markdown 预览与文件路径。
- **无数据**：全部查询键均无数据时提示未找到。
- **失败**：授权失败、债券无法解析、字段名非法、超出上限等，返回错误说明与处理建议。
