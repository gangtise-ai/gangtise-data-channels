# 发债主体基本信息（Open API · bond/issuer-info）

## 简介

返回发行人的企业性质、所属行业、地区、工商信息、最新主体评级（含境外机构）与存续债券列表等。单行型：每个发行人一行。脚本：`scripts/issuer_info.py`。

数据范围：

- **试用账号**与**正式账号**均支持查询全市场数据，覆盖上交所（`.SH`）、深交所（`.SZ`）、北交所（`.BJ`）、银行间（`.IB`）。
- **数据时效**：本接口返回最新状态数据，不区分历史版本，**无数据权限长度限制**。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `--securities` | 二选一 | 债券代码 / 简称 / 拼音，返回这些债券对应的发行人；结果带 `查询债券代码` 列 |
| `--issuers` | 二选一 | 公司全称或简称，逗号分隔。全称直接查询；简称只在唯一命中时换成全称，多家全部列出 |
| `--field-list` | 否 | 字段英文名或中文名，逗号分隔；传 `all` 返回全部字段。字段不在下表时直接报错并列出可选字段 |
| `-od` / `--output-dir` | 否 | 结果保存目录，建议绝对路径；文件名自动生成 |

## 字段说明

「默认」列标 ✓ 的为不传 `--field-list` 时返回的常用字段；查询键字段始终返回。

| 字段 | 中文列名 | 默认 | 说明 |
|------|----------|------|------|
| `issuerName` | 发行人 | 始终 | 发债主体（发行人）全称 |
| `unifiedSocialCreditCode` | 统一社会信用代码 | ✓ | 统一社会信用代码 |
| `enterpriseNature` | 企业性质 | ✓ | 企业性质 |
| `listedCompany` | 是否上市公司 | ✓ | 是否为上市公司 |
| `nationalIndustry` | 国民经济行业 |  | 所属国民经济一二级行业，格式 `国民经济一级/国民经济二级`，如 `"电力、热力、燃气及水生产和供应业/电力、热力生产和供应业"`；某一侧无数据时该侧以 `-` 占位 |
| `swIndustry` | 申万行业 | ✓ | 所属申万一二级行业，格式 `申万一级/申万二级`，如 `"公用事业/电力"`；某一侧无数据时该侧以 `-` 占位 |
| `establishmentDate` | 设立日期 | ✓ | 设立日期，格式 `yyyy-MM-dd` |
| `registeredCapital` | 注册资本(万元) | ✓ | 注册资本（单位：万元） |
| `registeredAddress` | 注册地址 |  | 注册地址 |
| `provinceCity` | 所属省市 | ✓ | 所属省市 |
| `legalRepresentative` | 法人代表 |  | 法人代表 |
| `generalManager` | 总经理 |  | 总经理 |
| `companyProfile` | 公司简介 |  | 公司简介 |
| `businessScope` | 经营范围 |  | 经营范围 |
| `website` | 公司网址 |  | 公司网址 |
| `telephone` | 联系电话 |  | 联系电话 |
| `email` | 电子邮箱 |  | 电子邮箱 |
| `latestIssuerRating` | 最新主体评级 | ✓ | 最新主体评级，**包含境外评级机构的评级**。展示规则：<br>• **有评级展望**时，为评级、评级展望、评级日期拼接的复合展示值，格式 `评级(展望,日期)`，如 `"AAA(维持,2023-06-27)"`；<br>• **无评级展望**时，**仅返回评级符号**，不带括号与日期，如 `"AAA"`；<br>• 无评级返回 `null`。<br>境外评级机构的评级沿用其自身的评级符号体系，与境内评级不可直接按符号比较，需结合 `ratingAgency` 识别 |
| `ratingAgency` | 评级机构 | ✓ | 评级机构 |
| `outstandingBondList` | 存续债券 | ✓ | 该主体当前**存续**债券的简称列表，多只以中文逗号 `，` 分隔，如 `"H1万科02，H2万科04，H2万科02"`；无存续债券返回 `null`。如需这些债券的代码或明细，请以简称调用**证券检索接口**换取代码后再查询相应接口 |

## 约束与说明

- `--securities` 与 `--issuers` 必须且只能传一个。
- 默认返回常用字段；公司简介、经营范围、联系方式等需 `--field-list all` 或显式指定。

## 调用示例

**按名称：**

```bash
python3 scripts/issuer_info.py --issuers 万科企业股份有限公司
```

**按债券：**

```bash
python3 scripts/issuer_info.py --securities H1万科04,23国债15
```

## 返回说明

- **成功**：在 `workspace/gangtise/issuer_info/` 下生成 `bond_*.csv`（列名为中文），回复中附 Markdown 预览与文件路径。
- **无数据**：全部查询键均无数据时提示未找到。
- **失败**：授权失败、债券无法解析、字段名非法、超出上限等，返回错误说明与处理建议。
