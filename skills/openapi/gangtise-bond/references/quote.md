# 债券日收盘行情（Open API · bond/daily-quote-exchange-cfets）

## 简介

返回交易所与银行间债券的日收盘行情：全价 / 净价 OHLC、到期收益率、成交量额、久期、凸性、应计利息等。仅历史收盘数据，无实时。多行型：每只债券每个交易日一行。脚本：`scripts/quote.py`。

数据范围：

- **试用账号**与**正式账号**均支持查询全市场数据，覆盖上交所（`.SH`）、深交所（`.SZ`）、北交所（`.BJ`）、银行间（`.IB`）。
- **数据权限长度**：**试用账号**为当前时间前溯 **3 年**、**正式账号**为前溯 **5 年**的历史存量数据。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `--securities` | 是 | 债券代码 / 简称 / 拼音，逗号分隔；亦可传 `.csv` 路径（读 `security_code` / `code` / `代码` / `债券代码` / `security_abbr` / `债券简称` 列）。非标准代码自动经债券检索解析 |
| `-sd` / `--start-date` | 否 | 开始日期 `yyyy-MM-dd`；不传默认近 7 日，近 7 日无数据（如长假）时自动放宽到近 30 日 |
| `-ed` / `--end-date` | 否 | 结束日期 `yyyy-MM-dd`；不传默认今天 |
| `--field-list` | 否 | 字段英文名或中文名，逗号分隔；传 `all` 返回全部字段。字段不在下表时直接报错并列出可选字段 |
| `-od` / `--output-dir` | 否 | 结果保存目录，建议绝对路径；文件名自动生成 |

## 约束与说明

- 接口按「日历天数 × 债券只数」不超过 10000 预估行数，脚本据此自动把债券分批请求，批量查询无需手动拆分。
- 开始日期早于账号可查询的历史区间（试用账号前溯 3 年、正式账号前溯 5 年）时返回 `110003`，请调晚开始日期。

## 调用示例

**指定区间：**

```bash
python3 scripts/quote.py --securities 23国债15 -sd 2026-09-01 -ed 2026-09-30
```

**指定字段：**

```bash
python3 scripts/quote.py --securities 019708.SH --field-list cleanClose,ytmClose,modifiedDuration,convexity
```

## 返回说明

- **成功**：在 `workspace/gangtise/quote/` 下生成 `bond_*.csv`（列名为中文），回复中附 Markdown 预览与文件路径。
- **无数据**：全部查询键均无数据时提示未找到。
- **失败**：授权失败、债券无法解析、字段名非法、超出上限等，返回错误说明与处理建议。
