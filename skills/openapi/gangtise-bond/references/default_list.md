# 违约债券列表（Open API · bond/default-list）

## 简介

返回违约债券的代码、简称、违约日期、违约金额、发行人与违约原因。同一债券可有多条违约记录。脚本：`scripts/default_list.py`。

数据范围：

- **试用账号**与**正式账号**均支持查询全市场违约债券，覆盖上交所（`.SH`）、深交所（`.SZ`）、北交所（`.BJ`）、银行间（`.IB`）。
- **数据时效**：不设历史区间限制。按日期查询时，单次区间不超过 **1 个自然年**（允许恰好一年）；更长区间由脚本自动拆分。

计费：成功返回按 **0.4 积分/次**，与条数、字段数无关。校验失败或该次查询全部无数据不计费。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `--securities` | 三选一 | 债券代码 / 简称 / 拼音，返回这些债券的历史违约记录 |
| `--issuers` | 三选一 | 发行人全称或简称。全称精确匹配；简称只在唯一命中时换成全称，多家全部列出。多个全称会逐个请求 |
| `-sd` / `--start-date` | 三选一 | 违约日期起始。不传债券和主体时，与 `-ed` 都不传则默认近 7 日 |
| `-ed` / `--end-date` | 与 `-sd` 同组 | 违约日期截止，包含当日 |
| `--field-list` | 否 | 字段英文名或中文名，逗号分隔；传 `all` 返回全部字段。字段不在下表时直接报错并列出可选字段 |
| `-od` / `--output-dir` | 否 | 结果保存目录，建议绝对路径；文件名自动生成 |

## 字段说明

不传 `--field-list` 返回全部字段。`securityCode`、`defaultDate` 始终返回，并排在表头最前。

| 字段 | 中文列名 | 默认 | 说明 |
|------|----------|------|------|
| `securityCode` | 债券代码 | 始终 | 债券代码 |
| `defaultDate` | 违约日期 | 始终 | 违约日期，格式 `yyyy-MM-dd` |
| `securityName` | 债券简称 | ✓ | 债券简称 |
| `defaultAmount` | 违约金额(亿元) | ✓ | 违约金额，单位亿元 |
| `issuerName` | 发行人 | ✓ | 发行人 |
| `defaultReason` | 违约原因 | ✓ | 违约原因；无原因时为空 |

## 约束与说明

- 日期、债券、发行人三种方式在接口侧互斥。脚本允许债券或主体**同时**带日期，此时先按债券/主体取历史记录，再在本地按违约日期过滤。
- 按日期查询时，区间超过 1 个自然年会拆成多次请求（恰好一年不拆）。2 月 29 日的下一年按 2 月 28 日计。
- `--issuers` 写全称时按发行人全称精确匹配。写简称时先查发债主体，并按同名债券反查发行人；名称里包含该关键词的主体有多家时全部列出，不自动选一家。
- 结果按违约日期降序、债券代码升序。全部无数据时提示未找到。

## 调用示例

**全市场近 7 日（默认）：**

```bash
python3 scripts/default_list.py
```

**指定日期：**

```bash
python3 scripts/default_list.py -sd 2026-09-01 -ed 2026-10-20
```

**按债券：**

```bash
python3 scripts/default_list.py --securities H1万科04
```

**按发行人全称：**

```bash
python3 scripts/default_list.py --issuers 万科企业股份有限公司
```

## 返回说明

- **成功**：在 `workspace/gangtise/default_list/` 下生成 `bond_*.csv`（列名为中文），回复中附 Markdown 预览与文件路径。
- **无数据**：全部查询条件均无记录时提示未找到。
- **失败**：授权失败、债券无法解析、字段名非法、日期区间非法等，返回错误说明。
