# Stock Screener

Turn a plain-language screen into indicator filters and return the names that match, within a sector or across all A-shares.

---

## When to use

- Run a first pass on a sector using financial, valuation, and market indicators
- Combine conditions (numeric filters and text matching) into a candidate pool
- See which companies fit a screening idea

## How to use

- "Baijiu names with ROE above 15% and market cap above RMB 50 billion"
- "All A-shares with PE below 20 and dividend yield above 4%"
- "Semiconductor companies listed year to date"

> This only screens; it does not rank. If a condition is ambiguous, the candidate readings are listed for you to confirm.

## Output

A table of matching stocks, with the indicators and conditions used.
