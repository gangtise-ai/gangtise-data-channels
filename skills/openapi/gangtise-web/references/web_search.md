# 联网搜索

脚本 `scripts/web_search.py` 调用 `POST /application/open-tool/web-search/search`。

服务端对公开网页做转载去重、信源分级（T0–T3）、黑名单剔除和内容打标后返回。调用方不要自己维护域名分级表，也不要尝试放行黑名单站点（显式指定会返回 `100003`）。

## 信源等级

| 等级 | 含义 | 例子 |
|------|------|------|
| `T0` | 官方一手：监管、交易所、市场基础设施、政府部门 | csrc.gov.cn、sse.com.cn |
| `T1` | 持牌或有编辑问责的媒体：通讯社、央媒、指定信披媒体、严肃财经媒体 | 新华社、四大证券报、财联社、第一财经 |
| `T2` | 财经平台资讯频道 | 东方财富、同花顺、新浪财经、腾讯财经 |
| `T3` | 未收录域名、自媒体、UGC、转载号 | 雪球帖、公众号、头条号、股吧 |

`B` 是黑名单，接口不返回。

## 内容特征

可同时出现多个；没有则为空，输出里不单列「特征」行。

| 标 | 输出 | 用法 |
|----|------|------|
| `rumor` | 传闻 | 只作线索 |
| `forward` | 转载 | 正文注明来源他站。引用监管原文时避开这条，去找无此标的 T0 |
| `disclaimer` | 免责声明 | 含「不构成投资建议」类声明 |
| `toutSuspect` | 疑似荐股 | 不要当事实或目标价 |
| `paywall` | 付费墙 | 正文不完整 |

## 时间

两条时间要分开用：

- **发布日期**（`publishTime`）：`yyyy-MM-dd`。排序和 `freshness` 只用它。为空表示规则给不出可信日期，不表示网页没有日期。
- **索引时间**（`indexTime`）：`yyyy-MM-dd'T'HH:mm:ss`，索引给什么就转述什么。不保证是发布时间。

发布日期判定顺序（命中即止）：

1. URL 路径里的日期段 → 依据「URL 日期」
2. 转载簇里更早的可信日期 → 依据「转载簇」（只向更早修正）
3. 已拉取的正文开头有「日期：/发布时间：」标签 → 依据「正文日期」（只有 `--include-content` 时可能出现）
4. 索引时间通过疑点检查（不是 `00:00:00`、同域同日没有扎堆、与摘要电头相差不超过 30 天）→ 依据「索引疑点检查」
5. 否则发布日期为空

`freshness` 为 `day` / `week` / `month` 时，结果里不会出现空的发布日期。

## 输出字段

汇总：实际检索词（`siteList` 会展开成 `site:` 写在这里）、返回条数、提示。

每条：标题、链接、站点、摘要、正文、正文是否截断、索引时间、发布日期、发布日期依据、信源等级、内容特征、被替换来源。

`--json` 时这些字段保持接口原名。默认 Markdown 用中文标签。

未开 `--include-content` 时不输出正文。开了但某页取不到时，该条仍返回，正文标为获取失败，提示里会说明「部分页面正文获取失败」。

## 空结果

HTTP 200，返回 0 条，提示至少一条。这不是 `DATA_NOT_FOUND`，也不要当错误重试。常见原因：词没有命中、被 `minTier` 或 `freshness` 滤光。按提示改关键词、放宽时效或降低等级。

## 错误码

参数不合法会在发请求前被脚本拒绝，超限不会自动改小。

| code | 何时出现 |
|------|----------|
| `100001` | `query` 为空 |
| `100002` | 参数类型错误 |
| `100003` | `query` 超 200 字，或 `siteList` 不是合法主机名 / 命中黑名单 |
| `100005` | `freshness`、`minTier` 不在枚举内 |
| `100006` | `size` 超 20（含正文时超 5）、站点超过 10 个、`maxContentChars` 越界 |
| `240002` | 检索词命中敏感词 |
| `260001` | 检索服务不可用或超时。可稍后重试，本次不扣积分。不要把它理解成「没有结果」 |
| `999005` | 积分不足 |
| `999006` | 超出日调用上限或 QPS |

## 调用建议

1. 轻搜：只给 `-q`，需要时加 `--freshness`、`--min-tier`、`--site-list`。`-s` 默认 10，最大 20。
2. 看信源、特征和发布日期，决定哪几条值得引用。
3. 精读：对目标站点加 `--site-list` 和 `--include-content`，`-s` 取 1–5。
