# 行情与基本面数据

拉取 A 股、港股、美股及各类指数的行情、财务、估值、预期与行业数据，按证券名称即可查询。

---

## 适用场景

- 取日 K / 分钟 K / 实时快照，或 A 股资金流向
- 财务三大报表、主营构成、股东结构、一致预期
- 估值历史分位，判断当前估值水位
- 宏观/行业/产品指标时序（如汽车销量、商品价格）、题材与板块成分股

## 怎么用

- 「比亚迪近一年日 K，前复权」
- 「宁德时代近 5 年 PE、PB 及历史分位」
- 「贵州茅台按产品的主营构成和券商一致预期」
- 「低空经济题材的画像和成分股」

## 输出

结构化 CSV 数据表；题材画像为 Markdown 文档。
