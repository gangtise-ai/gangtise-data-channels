# Personal Data

Read and manage data you can access in the Gangtise terminal: personal and tenant stock pools, group messages, your meetings, recording transcripts, and the AI cloud drive.

---

## When to use

- Pull a personal or tenant stock pool and continue into quotes, research, and other analysis
- Review research discussion and leads in message groups
- Find meetings you attended, plus notes and transcripts of recordings
- Find, upload, and organize files in the AI cloud drive

## How to use

- "List all of my watchlists"
- "List the tenant stock pools I can see"
- "Pull the latest valuation for names in my core pool"
- "Transcript of the semiconductor meeting I attended last week"
- "Find solar-related files in the cloud drive"

> Access is limited to data the authorized user can view. Create, delete, and move actions are confirmed before they run. Creating, renaming, deleting, and editing stock-pool members applies to personal watchlists only.

## Output

Watchlists as CSV. Messages, meetings, and transcripts as summaries or Markdown. Cloud-drive files can be downloaded.
