# Personal Data

Read and manage your own data in the Gangtise terminal: watchlists, group messages, your meetings, recording transcripts, and the AI cloud drive.

---

## When to use

- Pull a watchlist and continue into quotes, research, and other analysis
- Review research discussion and leads in message groups
- Find meetings you attended, plus notes and transcripts of recordings
- Find, upload, and organize files in the AI cloud drive

## How to use

- "List all of my watchlists"
- "Pull the latest valuation for names in my core pool"
- "Transcript of the semiconductor meeting I attended last week"
- "Find solar-related files in the cloud drive"

> Access is limited to the currently authorized user. Create, delete, and move actions are confirmed before they run.

## Output

Watchlists as CSV. Messages, meetings, and transcripts as summaries or Markdown. Cloud-drive files can be downloaded.
