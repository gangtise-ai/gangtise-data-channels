# 个人数据

读取并管理你在 Gangtise 终端里有权查看的数据：个人与所属租户股票池、群消息、我的会议、录音速记、AI 云盘。

---

## 适用场景

- 调出个人自选股或所属租户股票池，衔接行情、研报等后续分析
- 回看消息群里的投研讨论与线索
- 查找自己参加过的会议、录音的速记与转写
- 在 AI 云盘中查找、上传、整理文件

## 怎么用

- 「列出我的所有自选股池」
- 「列出所属租户里我能看的股票池」
- 「把我核心池里的股票拉一下最新估值」
- 「我上周参加的半导体会议速记」
- 「在云盘里找一下光伏相关的文件」

> 仅能访问当前授权用户有权查看的数据；创建、删除、移动等操作执行前会先确认。股票池的创建、重命名、删除和加减证券只针对个人自选股。

## 输出

股票池为 CSV；消息、会议、速记为摘要或 Markdown 文档；云盘文件可下载。
